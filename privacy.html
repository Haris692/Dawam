Politique de confidentialité

Dernière mise à jour : 13 avril 2026

Cette politique de confidentialité décrit comment l'application Dawam collecte, utilise et protège vos informations.

1. Données collectées

Dawam collecte uniquement les données strictement nécessaires à son fonctionnement :

  • Token de notification push : généré par votre appareil pour vous envoyer des rappels spirituels. Il n'est associé à aucun identifiant personnel.
  • Préférences locales : vos paramètres (ville, horaires, objectifs) sont stockés localement sur votre appareil (localStorage) et ne sont pas transmis à nos serveurs.

2. Données non collectées

Dawam ne collecte pas :

  • Votre nom, adresse e-mail ou tout identifiant personnel
  • Votre localisation GPS
  • Vos données de navigation ou comportement dans l'app
  • Aucune donnée vendue ou partagée à des tiers à des fins publicitaires

3. Notifications push

Si vous activez les notifications, un token anonyme est envoyé à notre serveur (hébergé sur Cloudflare Workers) uniquement pour acheminer les rappels que vous avez configurés. Ce token ne permet pas de vous identifier personnellement. Vous pouvez désactiver les notifications à tout moment dans les réglages de votre appareil.

4. Services tiers

Dawam utilise Firebase / Firestore pour la fonctionnalité groupes (optionnelle). Les données de groupe (pseudonyme, dhikrs partagés) sont soumises à la politique de confidentialité de Google Firebase.

5. Sécurité

Les données sont transmises via HTTPS. Aucune donnée sensible n'est stockée sur nos serveurs.

6. Droits

Vous pouvez supprimer toutes vos données locales en désinstallant l'application. Pour toute question, contactez-nous à : haris.c@hotmail.fr

7. Modifications

Cette politique peut être mise à jour. La date en haut de page indique la version en vigueur.
